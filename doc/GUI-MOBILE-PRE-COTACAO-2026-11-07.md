# GuinchaFácil mobile e hero da pré-cotação

## Cabeçalho público

No mobile, o cabeçalho usa flexbox: menu hambúrguer à esquerda, logo somente com a imagem centralizada e botão circular de socorro à direita. O CSS deve ser carregado com versão para evitar cache antigo. O ícone compatível é `fa-triangle-exclamation`; `fa-brake-warning` não está disponível no pacote Font Awesome carregado.

## Próximo ajuste

A pré-cotação deve usar o mapa Leaflet como hero de fundo, com pinos e rotas alimentados progressivamente pelo fluxo. Os formulários permanecem sobrepostos em painel legível e a navegação de etapas não deve criar rolagem horizontal ou deslocamento desnecessário no mobile.
