# Assets locais de fabricantes

## Proveniência

Os arquivos incorporados foram obtidos do repositório `vehiclespecs/brand-logos` em 12/08/2026. A estrutura do repositório é MIT, mas os logotipos permanecem marcas dos respectivos titulares e são usados apenas para identificação do fabricante, sem indicar patrocínio ou afiliação. O sistema não baixa assets externos automaticamente.

Coloque aqui somente imagens obtidas com licença compatível ou fornecidas/autorizadas pelo fabricante.

O nome do arquivo deve ser o slug em ASCII do fabricante, por exemplo `volkswagen.svg`, `toyota.png` ou `byd.webp`.
O sistema nunca baixa logos externos automaticamente: quando o arquivo não existe, exibe o badge de inicial e o ícone Font Awesome do tipo de veículo.
